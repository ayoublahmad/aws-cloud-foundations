## 5 Hands-on Labs

The repository currently contains three practical labs:

- [Build my own VPC and launch a web server](labs/build_my_own_VPC_and_aunch_web_erver/README.md)
  - VPC, public and private subnets, Internet Gateway, NAT Gateway, Security Groups and EC2
- [Build a database server with Amazon RDS](labs/rds-build-db-server/README.md)
  - RDS, MySQL, EC2, VPC, private subnets, Security Groups and Multi-AZ
- [Scale and load balance the architecture](labs/scale-and-load-balance/README.md)
  - AMI, Application Load Balancer, Target Group, Launch Template, Auto Scaling and CloudWatch

Each lab documents the objective, AWS services used, architecture, implementation steps,
screenshots, security considerations, challenges and lessons learned.
